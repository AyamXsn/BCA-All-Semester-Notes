## Repository contents
`Core-Computing-Notes/` contains independently written, general-purpose notes across common computing areas: computer fundamentals, programming, data structures, databases, operating systems, networking, software engineering, web development, and information security. These subjects are deliberately not assigned to RJU semesters.

`Programming-Practice/` contains standalone C, C++, Java, Python, JavaScript, SQL, and data-structure exercises. These are supplementary practice, not a verified RJU course list.

## Use this repository
1. Start with the official syllabus applicable to your BCA intake.
2. Compare its course titles and unit headings with the supplementary notes.
3. Use the notes to reinforce concepts, not as a replacement for official course materials.
4. Compile/run code yourself and record your environment.
5. Practise the questions; they are not guaranteed exam questions.
