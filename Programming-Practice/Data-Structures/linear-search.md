# Linear Search

Checks each element until a match is found or the collection ends.

- Best-case time: O(1).
- Worst-case time: O(n).
- Iterative auxiliary space: O(1).

Example: searching for 7 in `[4, 2, 7, 9]` checks 4, then 2, then 7; it returns index 2 (zero-based indexing).
