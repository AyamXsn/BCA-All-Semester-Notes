# Beginner Projects

## 1. Command-line calculator
Support addition, subtraction, multiplication, and division. Validate input and handle division by zero.

## 2. Student marks summary
Accept a set of marks, validate the range, calculate total and average, and report a result using a clearly stated grading rule.

## 3. Number guessing game
Generate a random target, accept guesses, and provide higher/lower hints. Limit attempts and handle invalid input.

## 4. Personal study planner
Store tasks, due dates, and completion status in a local file.

For each project, include source code, sample run, test cases, and known limitations.
