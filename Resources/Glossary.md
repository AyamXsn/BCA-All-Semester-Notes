# Glossary

| Term | Meaning |
|---|---|
| Algorithm | A finite sequence of well-defined steps for solving a problem. |
| API | Application Programming Interface; a contract for software components to interact. |
| Array | A sequence of elements accessed using an index. |
| Authentication | Verifying the identity of a user or system. |
| Compiler | A translator that converts source code into another representation. |
| Database | An organized collection of data. |
| Debugging | Finding, understanding, and correcting software defects. |
| Encapsulation | Bundling data and methods while controlling access to internal state. |
| Function | A reusable named block of code that performs a task. |
| Git | A distributed version control system. |
| HTTP | Hypertext Transfer Protocol, used for web communication. |
| IDE | Integrated Development Environment. |
| Inheritance | An OOP mechanism for deriving a class from another class. |
| IP address | A logical address used to identify an interface on an IP network. |
| Normalization | Organizing relational tables to reduce redundancy and update anomalies. |
| Operating system | System software that manages hardware and provides services to programs. |
| Polymorphism | The ability to use a common interface with different underlying implementations. |
| Recursion | A technique where a function solves a problem by calling itself on smaller inputs. |
| SQL | Structured Query Language for relational databases. |
| Version control | Recording and managing changes to files over time. |
