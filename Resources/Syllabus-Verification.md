# Syllabus Verification Record

**Date checked:** 2026-11-24
**University:** Rajarshi Janak University (RJU), Janakpurdham, Nepal
**Programme:** Bachelor in Computer Application (BCA), 4 years, 8 semesters, 128 credit hours

## Sources

1. Official programme page (subject tables for Semesters 1-8): <https://rju.edu.np/course/bca/>
2. Official curriculum PDF with detailed course outlines (titled "Curriculum of Bachelor in computer Application", dated 2075 BS): <https://rju.edu.np/wp-content/uploads/2018/08/BCA-full-syllabus-1.pdf>

## What has been verified

- All eight semester subject tables (codes, titles, credit hours) match between the programme page and the curriculum PDF.
- Credit totals per semester: 15, 16, 15, 17, 15, 17, 18, 15 = **128**, matching the official total.
- Course outlines (units, hours, labs, books) have been read for every subject in Semesters 1-5 and for HCAC-351 and HCAC-352.

## What is NOT yet verified

- Course outlines for 21 subjects still need to be retrieved (the fetch of the PDF was cut off during HCAC-353): HCAC-353, HCAC-354, HCAC-355, HCAPJ-356, HCAC-401, HCAOR-402, HCANP-403, HCAIN-404, HCAC-471, HCAMT-472, HCAC-473, HCAC-474, HCAC-475, HCAC-451, HCAPJ-452, HCAC-481, HCAC-482, HCAC-483, HCAC-484, HCAC-485, HCAC-486.
- Which electives a given college actually offers.

## Discrepancies found (verify with the university)

| Item | Detail |
|---|---|
| HMTH-153 vs HCAC-153 | Semester table: HMTH-153. Course outline for Math-II prints HCAC-153. |
| HCANP-403 title | Printed in legacy Preeti font encoding. A probable decoding is given in the subject README but is unconfirmed. |
| HCAC-302 semester label | Outline header says II/V; curriculum table says Semester 5. |
| Admission eligibility | The PDF says minimum 40% / 1.61 GPA; the live programme page says 45% / 1.8 GPA. The PDF may predate later revisions, so other content could also have changed. |
| Pass marks in HCAEC-303 | Printed as "4+16" in the PDF, which looks like a typo for 24+16. |

## Recommendation

The PDF is the 2075 BS curriculum, while the programme page was last modified on 2024-09-04. Confirm with your college or the [RJU Curriculum Development Centre](https://rju.edu.np/curriculum-development-centre/) that you are using the current version.
