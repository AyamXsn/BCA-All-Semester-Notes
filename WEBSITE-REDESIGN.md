# Website redesign handover

The visual redesign changes only the website presentation files:

- `index.html` — redesigned homepage structure and page copy.
- `assets/css/style.css` — colors, typography, spacing, responsive layout and card styling.
- `assets/js/main.js` — small-screen navigation toggle.
- `assets/img/study-collage.svg` — original vector illustration used as a source asset (the hero artwork is built with CSS/HTML; this SVG is available for optional use).

All existing course lists, semester folders, notes, source references, README files, tools and other repository content have been preserved from the supplied ZIP. The homepage links point to the existing repository paths.

## Publish

Upload the contents of this ZIP to the root of your existing GitHub repository, allowing the new `index.html` and `assets/` folder to replace/add the website files. Keep the `Semester-*`, `Core-Computing-Notes`, `Programming-Practice`, `Projects`, `Previous-Year-Questions`, `Resources`, and `Tools` folders in place.

The fonts are loaded from Google Fonts when a visitor has internet access; Georgia and Arial are used as fallbacks.
