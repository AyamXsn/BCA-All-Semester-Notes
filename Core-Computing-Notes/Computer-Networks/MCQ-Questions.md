# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. How many layers are in the OSI model?
A. 4
B. 5
C. 7
D. 8

**Correct answer: C.** The OSI reference model has seven layers.

## 2. Which protocol resolves domain names?
A. DNS
B. FTP
C. SMTP
D. SSH

**Correct answer: A.** DNS resolves names to resource records.

## 3. TCP provides:
A. Reliable ordered byte stream
B. No acknowledgements ever
C. Only broadcast
D. Physical addressing

**Correct answer: A.** TCP provides reliable, ordered byte-stream service.
