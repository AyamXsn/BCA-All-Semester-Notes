# Network Security Basics

## 1. Security goals
Confidentiality prevents unauthorized disclosure. Integrity protects against unauthorized alteration. Availability keeps services accessible. Authentication verifies identity; authorization controls permitted actions.

## 2. Common threats
Eavesdropping, spoofing, phishing, malware, denial of service, man-in-the-middle attacks, and credential theft.

## 3. Defensive controls
Use encryption in transit, secure authentication, least privilege, firewalls, patching, network segmentation, logging, backups, and incident response plans.

## 4. TLS and HTTPS
TLS provides cryptographic protection for a connection, including authentication of the server when certificate validation succeeds. HTTPS is HTTP carried over TLS.

## 5. Safe practices
Use unique passwords and a password manager, enable multi-factor authentication, verify URLs, keep systems updated, and avoid sending secrets over untrusted channels.

## 6. Exercises
Explain the difference between authentication and authorization. Describe how a firewall and TLS address different risks.
