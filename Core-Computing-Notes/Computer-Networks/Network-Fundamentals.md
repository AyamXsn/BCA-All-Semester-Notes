# Network Fundamentals

## 1. Network
A computer network connects devices so they can exchange data and share resources.

## 2. Network types
- PAN: personal area network.
- LAN: local area network.
- MAN: metropolitan area network.
- WAN: wide area network.

These labels describe scope, not necessarily a particular technology.

## 3. Topologies
Star, bus, ring, mesh, tree, and hybrid are common logical/physical topology descriptions. A star is easy to manage centrally but depends on its central device. Mesh provides alternate paths at higher cabling/port cost.

## 4. Transmission media
Guided media include twisted pair, coaxial cable, and optical fibre. Unguided media include radio, microwave, and infrared. Selection depends on bandwidth, distance, interference, cost, and environment.

## 5. Switching
Circuit switching reserves a path/resource for a session. Packet switching divides data into packets that may share network links.

## 6. Performance
Bandwidth is a capacity measure; throughput is achieved data rate. Latency is delay. Jitter is variation in delay. Packet loss is the fraction of packets that fail to arrive.
