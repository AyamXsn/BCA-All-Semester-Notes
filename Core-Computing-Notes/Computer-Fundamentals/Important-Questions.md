# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define a computer system and name its main functional units.
2. Differentiate data and information.
3. What is volatile memory?
4. Define firmware.
5. What is the role of the control unit?

## Long questions
1. Explain the functional units of a computer with a labelled block diagram.
2. Compare primary memory and secondary storage.
3. Explain binary, decimal, octal, and hexadecimal number systems with conversions.
4. Explain Boolean logic gates using truth tables.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
