# Computer System Overview

## 1. Introduction
A computer is an electronic system that accepts data, processes it according to instructions, stores information, and produces results. A computer system includes hardware, software, data, procedures, and people.

## 2. Basic functional units
- **Input unit:** receives data and instructions, for example a keyboard or scanner.
- **CPU:** executes instructions. It commonly contains the arithmetic logic unit (ALU), control unit, and registers.
- **Memory:** holds instructions and data currently in use.
- **Storage:** retains data when power is off, for example SSDs and hard disks.
- **Output unit:** presents results, for example a display or printer.

## 3. Instruction cycle
A simplified CPU instruction cycle is fetch, decode, execute, and store/write back. The control unit coordinates the steps. Modern processors use pipelines, caches, and multiple cores, so real execution can be more complex.

## 4. Memory hierarchy
| Type | Typical speed | Capacity/cost characteristic |
|---|---|---|
| CPU registers | Fastest | Very small, expensive per bit |
| Cache | Very fast | Small |
| RAM | Fast | Main working memory; volatile |
| SSD/HDD | Slower than RAM | Persistent, larger |
| Backup/archive | Often slower | Long-term retention |

**Volatile memory** loses its contents when power is removed. **Non-volatile storage** retains data.

## 5. Software
- System software manages hardware and provides a platform.
- Application software performs user tasks.
- Utility software performs maintenance or support tasks.
- Firmware is software stored in a device to control its basic operation.

## 6. Data versus information
Data are recorded facts or symbols. Information is data interpreted in context to support understanding or decisions.

## 7. Characteristics and limitations
Computers can process data quickly, repeat operations consistently, and store large quantities. They do not independently guarantee that input data, program logic, or output interpretation is correct.

## 8. Summary
A computer system combines input, processing, memory, storage, and output under software control. Understanding the role of each unit helps explain performance and system design.
