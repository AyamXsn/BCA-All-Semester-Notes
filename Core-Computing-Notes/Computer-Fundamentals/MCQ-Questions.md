# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which unit performs arithmetic and logical operations?
A. ALU
B. Control Unit
C. Input Unit
D. Storage Unit

**Correct answer: A.** The ALU performs arithmetic and logical operations.

## 2. Which memory is normally volatile?
A. SSD
B. RAM
C. ROM
D. Optical disc

**Correct answer: B.** Main RAM is typically volatile.

## 3. What is the base of hexadecimal?
A. 2
B. 8
C. 10
D. 16

**Correct answer: D.** Hexadecimal uses sixteen symbols, 0–9 and A–F.
