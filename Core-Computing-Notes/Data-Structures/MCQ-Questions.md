# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. A stack follows:
A. FIFO
B. LIFO
C. Random order
D. Priority only

**Correct answer: B.** A stack is Last In, First Out.

## 2. Binary search requires data to be:
A. Sorted
B. Duplicated
C. Linked
D. Encrypted

**Correct answer: A.** Binary search repeatedly halves a sorted search interval.

## 3. BFS commonly uses a:
A. Stack
B. Queue
C. Heap
D. Hash only

**Correct answer: B.** A queue supports breadth-first exploration.
