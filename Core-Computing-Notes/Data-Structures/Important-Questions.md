# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define a data structure.
2. What is an ADT?
3. Define stack and queue.
4. What is a collision in hashing?
5. What is a binary search tree?

## Long questions
1. Compare arrays and linked lists.
2. Explain stack and queue operations with applications.
3. Explain tree traversals with examples.
4. Compare linear search and binary search.
5. Explain BFS and DFS.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
