# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define an algorithm.
2. What is a flowchart?
3. Differentiate compiler and interpreter at a high level.
4. What is a variable?
5. Define recursion.

## Long questions
1. Explain algorithm characteristics and common flowchart symbols.
2. Explain sequence, selection, and iteration with examples.
3. Describe functions, parameter passing, scope, and return values.
4. Explain testing and debugging with examples of error types.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
