Algorithms and Flowcharts

1. Algorithm

An algorithm is a finite, ordered set of unambiguous steps that transforms input into output or solves a defined problem.

2. Qualities of a good algorithm

  • Input and output are clearly specified.
  • Each step is definite and executable.
  • It terminates after a finite number of steps.
  • It produces correct results for valid inputs.
  • Its resource use is reasonable.

3. Example: maximum of two numbers

  1. Read A and B.
  2. If A is greater than B, display A.
  3. Otherwise, display B.
  4. Stop.

Pseudocode:

READ A, B
IF A > B
    PRINT A
ELSE
    PRINT B
END IF

4. Flowcharts

A flowchart is a diagram showing process flow. Common symbols:

Symbol Meaning
Oval Start/stop
Rectangle Process
Parallelogram Input/output
Diamond Decision
Arrow Direction of control flow

5. Dry run

A dry run traces each step using sample input. It helps detect logic errors before executing code.

6. Algorithm analysis

Time complexity estimates how execution work grows with input size. Space complexity estimates additional memory use. Big-O notation describes an asymptotic upper bound, such as O(1), O(log n), O(n), O(n log n), or O(n²).

7. Exercises

Write an algorithm to find the smallest of three numbers, calculate factorial iteratively, and determine whether a number is prime.
