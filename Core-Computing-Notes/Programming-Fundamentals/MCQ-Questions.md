# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which flowchart symbol commonly represents a decision?
A. Oval
B. Diamond
C. Rectangle
D. Arrow

**Correct answer: B.** A diamond represents a decision/branch.

## 2. Which complexity grows linearly with n?
A. O(1)
B. O(log n)
C. O(n)
D. O(n²)

**Correct answer: C.** O(n) is linear.

## 3. A recursive function must have a:
A. Global variable
B. Base case
C. Pointer
D. Class

**Correct answer: B.** A base case stops recursive calls.
