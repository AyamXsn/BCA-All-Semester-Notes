# Variables, Data Types, and Operators

## 1. Variables
A variable is a named storage location or binding used by a program. Its value may change during execution, subject to the language's rules.

## 2. Data types
Common categories:
- Integer: whole numbers.
- Floating point: approximate real numbers.
- Character/string: text.
- Boolean: true/false.
- Composite types: arrays, records, objects, and collections.

The exact type system differs between languages. Some are statically typed; others are dynamically typed.

## 3. Operators
- Arithmetic: addition, subtraction, multiplication, division, remainder.
- Relational: equality and ordering comparisons.
- Logical: AND, OR, NOT.
- Assignment: store/update a value.
- Bitwise: operate on individual bits.
- Conditional: select a value based on a condition in languages that support it.

## 4. Expressions and precedence
An expression combines values, variables, and operators. Parentheses make intended evaluation order explicit. Do not rely on memorized precedence when a short pair of parentheses makes code clearer.

## 5. Type conversion
Implicit conversion is performed by language rules. Explicit conversion (casting) is requested by the programmer. Conversions can lose information, such as converting a floating-point value to an integer.

## 6. Good practices
Use meaningful names, initialize variables before reading them, choose appropriate types, and validate external input.
