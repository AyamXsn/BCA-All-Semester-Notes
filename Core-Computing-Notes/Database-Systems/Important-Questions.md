# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define DBMS.
2. What is a primary key?
3. What is a foreign key?
4. Define normalization.
5. What does SQL stand for?

## Long questions
1. Explain the three-schema database architecture.
2. Explain keys and integrity constraints with examples.
3. Describe SQL categories and common SELECT clauses.
4. Explain 1NF, 2NF, and 3NF.
5. Explain ACID properties.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
