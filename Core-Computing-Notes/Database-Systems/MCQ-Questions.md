# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which SQL clause filters groups?
A. WHERE
B. ORDER BY
C. HAVING
D. LIMIT

**Correct answer: C.** HAVING filters grouped results.

## 2. Which key references a key in another relation?
A. Foreign key
B. Candidate key
C. Superkey
D. Alternate label

**Correct answer: A.** A foreign key establishes a referential relationship.

## 3. Atomicity means:
A. All-or-nothing transaction
B. Fast query
C. Encrypted storage
D. Unique rows

**Correct answer: A.** Atomicity makes a transaction all-or-nothing.
