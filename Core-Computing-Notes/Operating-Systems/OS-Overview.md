# Operating System Overview

## 1. Definition
An operating system (OS) is system software that manages hardware resources and provides services and abstractions for applications.

## 2. Main responsibilities
- Process and thread management.
- Memory allocation and virtual memory.
- File and storage management.
- Device and I/O management.
- Security, protection, and user accounts.
- Networking and system services.

## 3. Kernel and user mode
The kernel runs with privileged access. User applications run with restricted privileges and request services through system calls. This separation helps protect the system.

## 4. OS types
Examples include batch, time-sharing, real-time, distributed, network, embedded, and mobile operating systems. These categories can overlap.

## 5. Interface
A command-line interface accepts textual commands. A graphical user interface uses visual elements such as windows, icons, and menus.

## 6. Summary
The OS coordinates resources and offers controlled abstractions so applications can use hardware without directly managing every device detail.
