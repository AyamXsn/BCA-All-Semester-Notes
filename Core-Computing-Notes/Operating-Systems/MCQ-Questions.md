# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which is a CPU scheduling algorithm?
A. Round Robin
B. RSA
C. HTML
D. Normalization

**Correct answer: A.** Round Robin allocates CPU time slices.

## 2. A page fault occurs when:
A. A needed page is not present in memory mapping
B. A printer fails
C. A file is renamed
D. A CPU overheats

**Correct answer: A.** The OS must handle a reference to a non-present page.

## 3. Which is not a deadlock necessary condition?
A. Mutual exclusion
B. Hold and wait
C. Circular wait
D. Compilation

**Correct answer: D.** Compilation is not one of the four classic conditions.
