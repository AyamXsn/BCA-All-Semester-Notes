# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define operating system.
2. What is a process?
3. Differentiate process and thread.
4. Define context switch.
5. What is a page fault?

## Long questions
1. Explain process states with a diagram.
2. Compare FCFS, SJF, priority, and Round Robin scheduling.
3. Explain paging and virtual memory.
4. Explain deadlock and its four necessary conditions.
5. Describe file allocation methods.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
