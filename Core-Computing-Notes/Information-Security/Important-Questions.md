# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define confidentiality.
2. What is authentication?
3. Differentiate encryption and hashing.
4. What is phishing?
5. Define least privilege.

## Long questions
1. Explain the CIA triad with examples.
2. Compare symmetric and asymmetric cryptography.
3. Explain authentication, authorization, and MFA.
4. Discuss common web application security risks.
5. Explain defence in depth.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
