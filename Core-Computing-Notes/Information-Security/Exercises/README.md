# Information Security Exercises

1. Define the problem and list assumptions before solving it.
2. Prepare a worked example by hand.
3. Implement or diagram the concept where applicable.
4. Test at least one normal case, one boundary case, and one invalid case.
5. Write a short reflection describing what you learned.

Use the topic files in this directory as the learning reference. These are general supplementary exercises, not official RJU assignments.
