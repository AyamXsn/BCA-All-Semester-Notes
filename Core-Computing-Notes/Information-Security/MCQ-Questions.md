# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which property protects data from unauthorized disclosure?
A. Confidentiality
B. Availability
C. Latency
D. Portability

**Correct answer: A.** Confidentiality concerns preventing unauthorized disclosure.

## 2. A cryptographic hash is generally:
A. One-way digest function
B. Reversible encryption
C. A network cable
D. A database key

**Correct answer: A.** Hashing maps input to a fixed-size digest and is not encryption.

## 3. MFA uses:
A. Two or more different factor categories
B. Two usernames
C. Only a long password
D. Only a CAPTCHA

**Correct answer: A.** MFA combines distinct factor categories.
