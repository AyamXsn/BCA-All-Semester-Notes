# Security Principles and Threats

## 1. CIA triad
Confidentiality protects information from unauthorized disclosure. Integrity protects correctness and completeness. Availability ensures authorized access when needed.

## 2. Threat, vulnerability, and risk
A threat can cause harm. A vulnerability is a weakness. Risk considers the likelihood and impact of a threat exploiting a vulnerability.

## 3. Common attacks
Phishing, malware, credential stuffing, injection, denial of service, social engineering, and misconfiguration.

## 4. Controls
Preventive controls reduce likelihood; detective controls identify events; corrective controls help restore systems. Examples include MFA, patching, logging, backups, encryption, and least privilege.

## 5. Defence in depth
Use multiple complementary security layers so one failed control does not expose the entire system.
