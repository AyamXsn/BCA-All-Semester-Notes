# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. A use-case diagram primarily shows:
A. Actors and goals
B. CPU registers
C. SQL indexes
D. Memory pages

**Correct answer: A.** Use-case diagrams show actors and system interactions/goals.

## 2. Regression testing checks:
A. Existing behaviour after changes
B. Only network speed
C. Only source formatting
D. Database size

**Correct answer: A.** Regression tests detect unintended effects of changes.

## 3. High cohesion is generally:
A. Desirable
B. Always harmful
C. A database error
D. A network topology

**Correct answer: A.** High cohesion keeps related responsibilities together.
