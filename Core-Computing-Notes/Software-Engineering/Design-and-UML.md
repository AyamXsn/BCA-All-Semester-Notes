# Design Principles and UML

## 1. Software design
Design transforms requirements into a structure that developers can implement. It considers components, interfaces, data, deployment, and quality attributes.

## 2. Core principles
- Abstraction: focus on essential details.
- Modularity: divide a system into manageable components.
- Encapsulation: hide internal implementation behind interfaces.
- High cohesion: keep related responsibilities together.
- Low coupling: minimize unnecessary dependencies.
- Separation of concerns: isolate different responsibilities.

## 3. UML diagrams
- Use-case diagram: actors and system goals.
- Class diagram: classes, attributes, operations, and relationships.
- Sequence diagram: messages over time.
- Activity diagram: workflow.
- State machine diagram: state transitions.
- Component/deployment diagrams: implementation structure and runtime placement.

## 4. Relationships
Association links classes. Generalization represents inheritance. Aggregation and composition model whole-part relationships with different ownership/lifetime implications.
