# Software Process and Lifecycle

## 1. Software engineering
Software engineering applies systematic, disciplined methods to develop, operate, and maintain software.

## 2. SDLC activities
Typical activities include planning, requirements, design, implementation, testing, deployment, and maintenance. Real projects revisit activities as learning and change occur.

## 3. Process models
- Waterfall: sequential phases; changes late in the process can be costly.
- Iterative: refine the product through repeated cycles.
- Incremental: deliver functionality in increments.
- Spiral: risk-driven repeated cycles.
- Agile approaches: emphasize feedback, collaboration, and adaptation.

No process model is best for every project.

## 4. Quality attributes
Correctness, reliability, usability, performance, security, maintainability, portability, and accessibility may all matter.

## 5. Exercises
Select a process approach for a small student project and justify it based on requirements uncertainty, feedback frequency, and risk.
