# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. Define software engineering.
2. What is a functional requirement?
3. Define cohesion.
4. What is regression testing?
5. Name two UML diagrams.

## Long questions
1. Explain the software development life cycle.
2. Differentiate functional and non-functional requirements.
3. Explain cohesion and coupling.
4. Describe black-box and white-box testing.
5. Explain software maintenance types.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
