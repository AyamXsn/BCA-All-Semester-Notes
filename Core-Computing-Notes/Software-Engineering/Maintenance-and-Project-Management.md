# Maintenance and Project Management

## 1. Software maintenance
- Corrective: fix defects.
- Adaptive: adjust to changed environments.
- Perfective: improve features or performance.
- Preventive: reduce future maintenance risk.

## 2. Project planning
Planning identifies scope, deliverables, tasks, dependencies, resources, schedule, risks, and acceptance criteria.

## 3. Estimation
Estimates are uncertain. Break work into smaller tasks, state assumptions, use historical evidence where available, and revise estimates as new information appears.

## 4. Risk management
Identify risks, estimate likelihood/impact, plan responses, assign owners, and monitor triggers.

## 5. Version control
A version control system records changes, supports collaboration, and enables comparison/recovery. Use meaningful commits and review changes before merging.
