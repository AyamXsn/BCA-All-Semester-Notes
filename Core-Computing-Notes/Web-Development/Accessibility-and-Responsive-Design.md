# Accessibility and Responsive Design

## 1. Accessibility
Accessible design aims to make software usable by people with different abilities and assistive technologies.

## 2. Practical principles
- Use semantic HTML.
- Ensure keyboard access and visible focus.
- Associate labels with form controls.
- Provide text alternatives for meaningful images.
- Use sufficient colour contrast.
- Do not communicate meaning through colour alone.
- Use headings in a logical hierarchy.
- Provide clear error messages.

## 3. Responsive design
Responsive interfaces adapt to screen size and user settings. Use flexible grids, relative sizing, media queries, and content-driven breakpoints.

## 4. Testing
Test with keyboard-only navigation, zoom, different viewport widths, screen-reader checks, and automated accessibility tools. Automated checks cannot identify every usability barrier.

## 5. Exercise
Audit a web form for keyboard navigation, labels, error messages, focus order, and contrast.
