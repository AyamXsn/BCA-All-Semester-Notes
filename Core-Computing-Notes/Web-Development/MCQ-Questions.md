# MCQ Practice

> Original supplementary MCQs. Correct answers and explanations are provided after each question.

## 1. Which HTML element represents the main content?
A. main
B. blink
C. font
D. center

**Correct answer: A.** The main element identifies dominant page content.

## 2. CSS primarily controls:
A. Presentation
B. Database transactions
C. IP routing
D. CPU scheduling

**Correct answer: A.** CSS controls document presentation.

## 3. Which HTTP status class indicates client errors?
A. 2xx
B. 3xx
C. 4xx
D. 5xx

**Correct answer: C.** 4xx codes indicate client errors.
