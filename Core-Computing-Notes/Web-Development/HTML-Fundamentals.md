# HTML Fundamentals

## 1. HTML
HTML (HyperText Markup Language) structures web content. Elements are represented using tags and may have attributes.

## 2. Basic document
```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My Page</title>
</head>
<body>
  <h1>Welcome</h1>
  <p>A simple web page.</p>
</body>
</html>
```

## 3. Semantic elements
Use elements such as `header`, `nav`, `main`, `article`, `section`, `aside`, and `footer` according to their meaning. Semantic markup improves structure and can help assistive technologies.

## 4. Forms
Forms collect user input using controls such as `input`, `select`, `textarea`, and `button`. Associate labels with controls and validate input on both client and server.

## 5. Links and images
Use descriptive link text. Supply meaningful `alt` text for informative images; use empty alt text for decorative images where appropriate.

## 6. Exercises
Create a semantic profile page, a contact form with labels, and a table with captions and headers.
