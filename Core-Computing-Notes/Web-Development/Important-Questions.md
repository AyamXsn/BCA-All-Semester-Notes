# Practice Questions

> These are original supplementary practice questions, not official RJU questions and not predictions of examination content.

## Short questions
1. What is HTML?
2. What is CSS used for?
3. Define DOM.
4. What is HTTP?
5. What is responsive design?

## Long questions
1. Explain client-server web architecture and HTTP request/response.
2. Describe semantic HTML and forms.
3. Explain CSS box model and layout systems.
4. Explain JavaScript events and asynchronous programming.
5. Discuss web accessibility principles.

## Programming / applied questions
1. Create a small practical exercise that demonstrates one core concept from this topic.
2. Trace or analyse a worked example and explain each step.
3. Identify boundary cases and propose suitable tests.
