# Contributing

## Academic accuracy
- Do not guess RJU course names, course codes, semester placement, credits, or units.
- For RJU-specific additions, cite an official university syllabus/notice and record the applicable batch, version, publication date, URL, and access date.
- Keep general supplementary material clearly labelled as such.
- Do not describe generated questions as previous-year questions or likely/guaranteed examination questions.

## Notes
- Write in plain, student-friendly English.
- Explain terminology before using it.
- Include examples, comparisons, diagrams, applications, and a recap where appropriate.
- Write original explanations; do not reproduce textbooks or paid notes.
- Each topic belongs in its own Markdown file.

## Programs
- Keep unrelated programs in separate files.
- Add comments, logic explanation, compile/run steps, sample input/output, and expected result.
- Test before claiming tested. Mention compiler/interpreter version where possible.
- Never commit credentials, private keys, or personal data.

## Papers and sources
- Authentic papers need a legitimate source and provenance.
- Generated practice sets must carry the exact label `Practice Question Paper - AI Generated`.
- Cite external references and respect their terms.

## Pull requests
Run `python Tools/validate_repository.py`, summarize the changes, and include evidence for any syllabus-specific change.
