# Previous-Year Question Papers

No authentic RJU question papers are included unless a legitimate source is verified and documented. A file's presence alone does not prove authenticity.

For each authentic paper, record university, programme, course title/code, semester, exam session/year, official/public source URL, access date, and permission/public availability basis.

Generated questions must be labelled exactly **Practice Question Paper - AI Generated** and kept separate from authentic past papers. Store answer keys separately from question papers.
