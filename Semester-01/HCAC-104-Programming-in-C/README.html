RJU BCA · STUDENT ARCHIVE

HCAC-104 - Programming in C

Semester: 1 (First Year) | Credit hours: 3 | Full marks: 60 + 20 + 20 (pass 24 + 8 + 8) | Nature: Theory + Lab

Subject Introduction

This course teaches structured programming in C: writing, compiling, debugging and running programs, designing algorithms and flowcharts, and using arrays, pointers, strings, structures, files and basic graphics.

Source: official RJU curriculum outline (PDF, programme page), transcribed and condensed here.

Syllabus Units

Allotted lecture hours listed in the outline: 45.

Unit Title Hours Topics (condensed) Status
I Introduction to Programming Concept 4 Language translators, syntax and semantics, algorithm/flowchart/pseudocode, features of a good program, procedural, modular and object-oriented techniques. Notes complete
II Introduction to C 6 History, structure of a C program, character set, tokens, keywords, comments, variables and constants, data types, type conversion, input/output, operators. Notes complete
III Control Structure 7 if, if-else, nested if-else, switch, conditional operator, while, do-while, for, nested loops, goto, break, continue, exit. Notes complete
IV Function 6 Function definition and return, prototype, call by value, call by reference, recursion. Notes complete
V Array, Pointer and String 7 Arrays (one and multi-dimensional), strings and string functions, passing arrays and strings to functions, pointers, pointer arithmetic, arrays and pointers. Notes complete
VI Structure and Union 7 Structures, initialisation and access, arrays of structures, structures and functions, pointer to structure, union, union vs structure. Notes complete
VII Input Output and File Handling 5 File handling concepts and access methods, fopen, fclose, fflush, freopen, formatted/character/direct I/O, random access, error handling. Notes complete
VIII Introduction to Graphics 3 Graphics modes, initialisation, graphics functions. Notes complete
