# Unit III: Control Structures

**Subject:** HCAC-104 Programming in C | **Semester:** 1 | **Allotted time (official):** 7 hours

## 1. What This Unit Covers

By default, statements run one after another (sequence). **Control structures** change that order. The official syllabus topics are:

1. Selection: `if`, `if-else`, nested `if-else`, `switch`, conditional operator
2. Loops: `while`, `do-while`, `for`, nested loops
3. Jump statements: `goto`, `break`, `continue`, `exit`

## 2. The Three Basic Structures

| Structure | Meaning | C features |
|---|---|---|
| Sequence | Statements run in order | Ordinary statements |
| Selection (decision) | Choose between paths | `if`, `switch`, `?:` |
| Iteration (repetition) | Repeat statements | `while`, `do-while`, `for` |
