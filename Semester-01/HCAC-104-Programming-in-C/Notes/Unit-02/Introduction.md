# Unit II: Introduction to C

**Subject:** HCAC-104 Programming in C | **Semester:** 1 | **Allotted time (official):** 6 hours

## 1. What This Unit Covers

This unit gives you the building blocks of every C program. The official syllabus topics are:

1. History of C, basic structure of a C program, character set
2. Tokens, keywords, comments
3. Variables and constants, rules for naming and declaring variables, data types
4. Type conversion, input and output
5. Operators: arithmetic, relational, logical, increment/decrement, assignment, bitwise, ternary (conditional), comma

## 4. Summary

Every C program has a fixed skeleton, uses a small set of tokens, stores data in typed variables, communicates through `printf` and `scanf`, and computes with operators. Master these and the later units (control flow, functions, arrays) become much easier.
