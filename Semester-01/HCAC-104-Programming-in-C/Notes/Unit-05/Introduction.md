# Unit V: Array, Pointer and String

**Subject:** HCAC-104 Programming in C | **Semester:** 1 | **Allotted time (official):** 7 hours

## 1. What This Unit Covers

Official syllabus topics: one- and multi-dimensional arrays, strings and string functions, passing arrays and strings to functions, pointers (address, declaration, assignment, initialization, arithmetic), and the relationship between arrays and pointers.

## 4. Summary

Arrays store many values of one type, strings are character arrays ending in `'\0'`, and pointers hold addresses. In C these three ideas are closely linked.
