# Unit VI: Structure and Union

**Subject:** HCAC-104 Programming in C | **Semester:** 1 | **Allotted time (official):** 7 hours

## 1. What This Unit Covers

Official syllabus topics: structures, initialization and member access, arrays of structures, structures and functions, pointer to structure, unions, and the difference between structure and union.

## 4. Summary

Arrays group values of one type; structures group values of different types into one record. Unions let several members share the same memory.
