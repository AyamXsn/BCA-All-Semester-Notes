Unit I: Introduction to Programming Concepts

Subject: HCAC-104 Programming in C | Semester: 1 | Allotted time (official): 4 hours

1. What This Unit Covers

Before writing any C code, you need to understand what a program is, how a computer turns your instructions into something it can run, and how to plan a solution on paper. This unit covers the official syllabus topics:

  1. Programming languages and language translators (assembler, compiler, interpreter), syntax and semantics
  2. Programming design tools: algorithm, flowchart, pseudocode
  3. Features of a good program
  4. Programming techniques: procedural, modular and object-oriented

2. Key Terms Explained First

Term Simple meaning
Program A set of instructions that tells a computer what to do.
Programming language A formal language used to write those instructions.
Source code The program as the programmer writes it (for example, a .c file).
Machine code The 0s and 1s the processor can execute directly.
Translator Software that converts source code into machine code.
Bug A mistake in a program.
Debugging Finding and fixing bugs.

Read the topics in the order above. The tested program that applies Topic 2 is in Program-01-Largest-of-Three-Numbers.

5. Summary

Programming is a process: understand the problem, design the solution with an algorithm and a flowchart, write code in a language, translate it to machine code, then test and fix it. This unit builds the vocabulary and planning habits that every later unit depends on.
