## D. Output Prediction Questions

Try each question first. Answers were verified by compiling and running the code.

**Q1.** What is printed?

```c
int a = 5, b = 2;
printf("%d %d %.1f", a / b, a % b, (float)a / b);
```

<details><summary>Answer</summary>

`2 1 2.5`. Integer division gives 2, the remainder is 1, and the cast makes the division real.

</details>

**Q2.** What is printed?

```c
for (i = 0; i < 5; i++) {
    if (i == 2) continue;
    if (i == 4) break;
    printf("%d ", i);
}
```

<details><summary>Answer</summary>

`0 1 3`. The pass with `i == 2` is skipped and the loop stops at `i == 4`.

</details>

**Q3.** What is printed?

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;
printf("%d %d", *(p + 2), arr[4]);
```

<details><summary>Answer</summary>

`3 5`. `*(p + 2)` is the third element and `arr[4]` is the last.

</details>

**Q4.** What does `f(4)` return?

```c
int f(int n)
{
    if (n == 0) return 0;
    return n + f(n - 1);
}
```

<details><summary>Answer</summary>

`10`, because `4 + 3 + 2 + 1 + 0 = 10`.

</details>

**Q5.** What is printed?

```c
char s[] = "HELLO";
s[0] = 'J';
printf("%s %zu", s, strlen(s));
```

<details><summary>Answer</summary>

`JELLO 5`. The first character is replaced; the length stays 5.

</details>

**Q6.** What is printed, and what is the mistake?

```c
int x = 10;
if (x = 5)
    printf("A");
else
    printf("B");
```

<details><summary>Answer</summary>

`A`. The condition uses `=` (assignment), which stores 5 in `x` and gives the non-zero value 5, so it is always true. The programmer almost certainly meant `==`. Compilers usually warn about this.

</details>

**Q7.** What are the final values of `r` and `n`?

```c
int n = 3, r = 1;
while (n > 0) {
    r *= n;
    n--;
}
```

<details><summary>Answer</summary>

`r = 6` and `n = 0` (3 x 2 x 1 = 6).

</details>

**Q8.** For `int u = 7;`, what are `u >> 1` and `u << 1`?

<details><summary>Answer</summary>

`3` and `14`. Shifting right by one divides by 2 (dropping the fraction); shifting left by one doubles.

</details>
