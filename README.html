Repository contents

  • Complete subject list — all eight semesters, course codes, credits and electives.
  • Semester-01/ through Semester-08/ — individual subject folders and course-level README files.
  • Core computing notes — general computing topics and supplementary notes.
  • Programming practice — C, C++, Java, Python, JavaScript, SQL and data-structure examples.
  • Projects — beginner, intermediate and advanced project ideas.
  • Previous-year questions — folders for organizing papers by semester.
  • Resources — study guidance, references and syllabus verification.
  • Validation tool — repository checks.

Academic-year and syllabus notice

The available subject tables are recorded from the RJU BCA programme page and the BCA curriculum PDF. The PDF is dated 2075 BS. This material does not by itself confirm that a revised syllabus for both 2025–26 and 2026–27 has been published or that every detail remains unchanged. Check with RJU or your college before using this index for course registration, exam preparation, or elective selection.

Known discrepancies and verification notes are documented in Resources/Syllabus-Verification.md.

How to use

  1. Open SUBJECT-LIST.md and select your semester.
  2. Open the corresponding course folder.
  3. Compare the course outline with the syllabus applicable to your intake.
  4. Use the general computing notes and programming practice as supplementary material.
  5. Add verified notes, practicals, and past papers to the matching course folder.

Important disclaimer

This is an independent student resource, not an official university publication. Course folders are learning-resource placeholders unless they contain actual notes. Subject names and credit totals are based on the available RJU materials; academic-year applicability, course details, and elective availability should be confirmed with the university/college.
